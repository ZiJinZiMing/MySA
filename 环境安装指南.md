# PortfolioRebalancingCalculator 环境安装指南

## 📋 系统要求

- **Python版本**: 3.8 或更高版本
- **操作系统**: Windows 10/11, macOS, Linux
- **Chrome浏览器**: 最新版本

## 🔧 安装步骤

### 1. 创建Python虚拟环境（推荐）

```bash
# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate
```

### 2. 安装Python依赖包

```bash
# 使用requirements.txt文件安装
pip install -r requirements.txt

# 或者手动安装各个包
pip install pandas numpy beautifulsoup4 selenium matplotlib seaborn lxml requests
```

## 📦 主要依赖包说明

| 包名 | 版本要求 | 用途 |
|------|----------|------|
| **pandas** | >=1.5.0 | 数据处理和分析 |
| **numpy** | >=1.24.0 | 数值计算 |
| **beautifulsoup4** | >=4.11.0 | HTML页面解析 |
| **selenium** | >=4.15.0 | 浏览器自动化 |
| **matplotlib** | >=3.6.0 | 图表绘制 |
| **seaborn** | >=0.12.0 | 统计图表美化 |
| **lxml** | >=4.9.0 | XML/HTML解析器 |
| **requests** | >=2.28.0 | HTTP请求 |

## 🌐 Chrome浏览器驱动配置

### 方法1: 自动管理（推荐）
```bash
# 安装webdriver-manager（自动下载和管理Chrome驱动）
pip install webdriver-manager
```

### 方法2: 手动下载
1. 查看Chrome版本：`chrome://version/`
2. 下载对应版本的ChromeDriver：https://chromedriver.chromium.org/
3. 将chromedriver.exe放入PATH环境变量中

```python
def test_chrome_driver():

    try:
        from selenium import webdriver
        from selenium.webdriver.chrome.options import Options
        
        chrome_options = Options()
        chrome_options.add_argument("--headless")  # 无头模式
        chrome_options.add_argument("--no-sandbox")
        chrome_options.add_argument("--disable-dev-shm-usage")
        
        driver = webdriver.Chrome(options=chrome_options)
        driver.get("https://www.google.com")
        print("✅ Chrome驱动测试成功")
        driver.quit()
        return True
        
    except Exception as e:
        print(f"❌ Chrome驱动测试失败: {e}")
        print("请检查Chrome浏览器和ChromeDriver是否正确安装")
        return False

if __name__ == "__main__":

    print("\n环境检测完成！")
```

## 🛠️ 常见问题解决

### 问题1: Chrome驱动版本不匹配
**解决方案**: 
```bash
pip install webdriver-manager
```
然后在代码中使用：
```python
from webdriver_manager.chrome import ChromeDriverManager
from selenium.webdriver.chrome.service import Service

service = Service(ChromeDriverManager().install())
driver = webdriver.Chrome(service=service)
```

### 问题2: matplotlib中文显示问题
**解决方案**: 安装中文字体
```bash
# Windows用户
# 系统已包含SimHei字体，无需额外安装

# macOS用户
# 下载并安装中文字体，或使用系统字体

# Linux用户
sudo apt-get install fonts-wqy-microhei
```

### 问题3: SSL证书错误
**解决方案**:
```bash
pip install --trusted-host pypi.org --trusted-host pypi.python.org --trusted-host files.pythonhosted.org -r requirements.txt
```

### 问题4: 权限问题（Windows）
**解决方案**: 以管理员身份运行命令提示符

## 🔄 使用现有浏览器实例

如果要使用已打开的Chrome浏览器：

1. **启动Chrome（调试模式）**:
```bash
# Windows
"C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir="C:\chrome_debug"

# macOS
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --remote-debugging-port=9222 --user-data-dir="/tmp/chrome_debug"

# Linux
google-chrome --remote-debugging-port=9222 --user-data-dir="/tmp/chrome_debug"
```

2. **代码中连接现有浏览器**:
```python
from selenium.webdriver.chrome.options import Options

chrome_options = Options()
chrome_options.add_experimental_option("debuggerAddress", "127.0.0.1:9222")
driver = webdriver.Chrome(options=chrome_options)
```
