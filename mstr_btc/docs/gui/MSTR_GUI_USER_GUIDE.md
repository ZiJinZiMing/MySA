# MSTR/BTC溢价监控GUI应用用户指南

## 应用概述

MSTR/BTC溢价监控GUI应用是一个实时监控MicroStrategy (MSTR) 股票相对于其比特币持有量溢价率的图形化工具。该应用提供直观的界面显示价格数据，并绘制溢价率的实时走势图。

## 系统要求

### 最低系统要求
- **操作系统**: Windows 10/11, macOS 10.15+, Ubuntu 18.04+
- **Python版本**: Python 3.8或更高版本
- **内存**: 至少2GB RAM
- **硬盘空间**: 500MB可用空间
- **网络**: 稳定的互联网连接

### 推荐系统要求
- **内存**: 4GB RAM或更高
- **硬盘空间**: 1GB可用空间
- **显示器**: 1920x1080分辨率或更高
- **网络**: 宽带互联网连接

## 前提条件设置

### Chrome浏览器配置
应用需要Chrome浏览器以远程调试模式运行：

1. **关闭所有Chrome实例**
2. **以调试模式启动Chrome**
   ```bash
   # Windows
   "C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222
   
   # macOS
   /Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --remote-debugging-port=9222
   
   # Linux
   google-chrome --remote-debugging-port=9222
   ```

3. **登录SeekingAlpha**
   - 在Chrome中访问 https://seekingalpha.com
   - 使用您的账户登录

### API密钥配置
应用使用Finnhub API获取价格数据：

1. **获取API密钥**
   - 访问 https://finnhub.io
   - 注册免费账户
   - 获取API密钥

2. **配置API密钥**
   - 方法1: 在应用设置中输入API密钥
   - 方法2: 设置环境变量 `FINNHUB_API_KEY`

### 界面元素说明

#### 1. 实时数据显示区域
- **MSTR价格卡片**: 显示当前MSTR股价和24小时变化
- **BTC价格卡片**: 显示当前比特币价格和24小时变化
- **溢价率卡片**: 显示计算得出的溢价率和状态指示

#### 2. 溢价走势图表
- **实时曲线**: 显示溢价率的时间序列变化
- **数据点**: 鼠标悬停查看具体数值
- **时间轴**: 可调整显示的时间范围
- **网格线**: 辅助读取数值

#### 3. 控制面板
- **开始监控**: 启动实时数据监控
- **停止监控**: 停止数据监控
- **清除数据**: 清空当前图表数据
- **设置**: 打开设置对话框
- **导出CSV**: 导出历史数据
- **更新间隔**: 设置数据更新频率
- **显示时间**: 设置图表显示的时间范围

#### 4. 状态栏
- **连接状态**: 显示API连接状态
- **最后更新**: 显示数据最后更新时间
- **数据点**: 显示当前存储的数据点数量

## 使用说明

### 基本使用流程

1. **启动应用**
   - 确保Chrome浏览器已以调试模式运行
   - 启动MSTR Monitor应用

2. **开始监控**
   - 点击"开始监控"按钮
   - 应用将自动获取BTC per share数据
   - 开始实时监控MSTR和BTC价格

3. **查看数据**
   - 观察实时数据卡片中的价格更新
   - 监控溢价走势图表的变化
   - 注意状态栏中的连接状态

4. **调整设置**
   - 根据需要调整更新间隔
   - 选择合适的图表显示时间范围
   - 通过设置菜单配置更多选项

5. **导出数据**
   - 点击"导出CSV"按钮
   - 选择保存位置和文件名
   - 数据将以CSV格式保存

### 高级功能

#### 1. 参数配置
- **更新间隔**: 支持5秒、10秒、30秒、60秒
- **显示时间**: 支持30分钟、1小时、4小时、1天
- **API配置**: 自定义API密钥和超时设置
- **界面主题**: 选择不同的颜色主题

#### 2. 数据导出
- **CSV格式**: 包含时间戳、价格、溢价率
- **图表截图**: 保存当前图表为图片
- **统计信息**: 导出数据统计摘要

#### 3. 告警功能
- **溢价阈值**: 设置溢价率告警阈值
- **价格告警**: 设置价格变化告警
- **声音提醒**: 开启声音告警提示

## 故障排除

### 常见问题

#### 1. 应用无法启动
**问题**: 双击应用图标后无响应
**解决方案**:
- 检查Python版本是否为3.8+
- 确保所有依赖库已正确安装
- 查看错误日志文件`mstr_monitor.log`

#### 2. 无法连接到Chrome
**问题**: 提示"Chrome连接失败"
**解决方案**:
- 确保Chrome以调试模式运行
- 检查端口9222是否被其他程序占用
- 重启Chrome浏览器

#### 3. API连接错误
**问题**: 提示"API连接失败"
**解决方案**:
- 检查网络连接
- 验证API密钥是否正确
- 确认API额度是否充足

#### 4. 数据更新缓慢
**问题**: 数据更新间隔过长
**解决方案**:
- 调整更新间隔设置
- 检查网络连接质量
- 减少显示的数据点数量

#### 5. 图表显示异常
**问题**: 图表不显示或显示错误
**解决方案**:
- 清除图表数据后重新开始
- 检查matplotlib库是否正确安装
- 重启应用程序

### 错误代码说明

| 错误代码 | 描述 | 解决方案 |
|---------|------|----------|
| E001 | Chrome连接失败 | 重启Chrome调试模式 |
| E002 | API密钥无效 | 检查并更新API密钥 |
| E003 | 网络连接超时 | 检查网络连接 |
| E004 | 数据解析错误 | 检查数据源格式 |
| E005 | 文件权限错误 | 检查文件读写权限 |

### 日志文件位置
- **Windows**: `%APPDATA%/MSTRMonitor/logs/`
- **macOS**: `~/Library/Application Support/MSTRMonitor/logs/`
- **Linux**: `~/.local/share/MSTRMonitor/logs/`
