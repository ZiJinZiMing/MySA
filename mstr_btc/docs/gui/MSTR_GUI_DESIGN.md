# MSTR/BTC溢价监控GUI应用设计方案

## 项目概述

本项目旨在将现有的命令行版本`mstr_btc.py`升级为具有图形用户界面的实时监控应用，提供MSTR/BTC溢价率的可视化显示和走势分析功能。

## 设计目标

### 主要目标
- 简化代码结构，保留核心价格获取功能
- 提供直观的GUI界面展示实时数据
- 实现溢价率的实时图表绘制
- 确保应用的稳定性和用户体验

### 功能特性
- **实时数据显示**: 显示MSTR价格、BTC价格和溢价率
- **动态图表**: 溢价率时间序列图表，支持实时更新
- **用户控制**: 开始/停止监控、清除数据、设置参数
- **状态监控**: 连接状态、最后更新时间、数据点数量显示
- **数据导出**: 支持CSV格式导出历史数据

### 界面区域功能

#### 1. 实时数据显示区域
- **MSTR价格卡片**: 显示当前MSTR股价和变化率
- **BTC价格卡片**: 显示当前BTC价格和变化率
- **溢价率卡片**: 显示计算出的溢价率和状态

#### 2. 图表显示区域
- **主图表**: 实时溢价率走势图
- **时间轴**: 可配置的时间范围(1小时/4小时/1天)
- **网格线**: 帮助读数的辅助线
- **数据点**: 鼠标悬停显示具体数值

#### 3. 控制面板
- **开始/停止按钮**: 控制数据监控状态
- **清除数据按钮**: 清空当前图表数据
- **设置按钮**: 打开设置对话框
- **导出按钮**: 导出历史数据为CSV文件
- **参数设置**: 更新间隔、显示时间范围

#### 4. 状态栏
- **连接状态**: API连接状态指示
- **最后更新时间**: 显示数据最后更新时间
- **数据点数量**: 当前存储的数据点数量

## 用户交互流程

### 启动流程
1. 用户启动应用
2. 系统初始化GUI界面
3. 自动获取BTC per share数据
4. 显示初始状态界面

### 监控流程
1. 用户点击"开始监控"
2. 系统启动数据获取线程
3. 定期调用API获取MSTR和BTC价格
4. 计算溢价率并更新图表
5. 更新实时数据显示

### 设置流程
1. 用户点击"设置"按钮
2. 弹出设置对话框
3. 用户修改参数(更新间隔、API密钥等)
4. 保存设置并应用

### 导出流程
1. 用户点击"导出CSV"
2. 弹出文件保存对话框
3. 系统将历史数据写入CSV文件
4. 显示导出成功消息

## 错误处理机制

### 网络错误处理
- **连接超时**: 显示连接错误状态，自动重试
- **API限流**: 自动调整请求频率
- **数据解析错误**: 记录错误日志，跳过当前数据点

### 用户操作错误
- **重复操作**: 按钮状态管理，防止重复点击
- **无效输入**: 参数验证和错误提示
- **文件权限**: 导出时检查文件权限

## 性能优化

### 内存管理
- 使用`collections.deque`限制数据点数量
- 定期清理过期数据
- 避免内存泄漏

### 响应性优化
- 数据获取与GUI更新分离到不同线程
- 使用异步方式更新图表
- 合理设置更新间隔
