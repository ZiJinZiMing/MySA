## 🎮 基本操作

### 启动监控

1. **检查前提条件**
   - Chrome浏览器以调试模式运行
   - 已在Chrome中登录SeekingAlpha
   - API密钥已正确配置

2. **启动应用**
   ```bash
   python3 mstr_gui.py
   ```

3. **开始监控**
   - 点击"开始监控"按钮
   - 观察状态栏连接指示变为绿色
   - 等待数据开始更新

### 停止监控
- 点击"停止监控"按钮
- 或使用快捷键 `Ctrl+S`
- 数据将停止更新，但已有数据保持显示

### 清除数据
- 点击"清除数据"按钮
- 确认清除操作
- 所有图表和统计数据将被重置

## 🔧 高级功能

### 自定义监控参数

#### 更新间隔设置
- **5秒**: 高频监控，适合短期交易
- **10秒**: 默认设置，平衡性能和实时性
- **15秒**: 中等频率，节省资源
- **30秒**: 低频监控，长期观察
- **60秒**: 最低频率，最少资源消耗

#### 显示时间范围
- **30分钟**: 短期趋势分析
- **1小时**: 默认设置，适合日内交易
- **2小时**: 中期趋势观察
- **4小时**: 较长时间趋势
- **8小时**: 半日趋势分析
- **1天**: 全日趋势概览

### 图表功能

#### 交互操作
- **缩放**: 鼠标滚轮缩放时间轴
- **平移**: 拖拽移动查看历史数据
- **工具提示**: 悬停显示精确数值
- **自动滚动**: 自动跟踪最新数据

#### 视觉指示
- **颜色编码**: 
  - 绿色: 正向变化
  - 红色: 负向变化
  - 蓝色: 无变化
- **线条样式**: 可在设置中自定义
- **网格显示**: 辅助读取数值

## 📊 数据导出

### 访问导出功能
- 点击"导出CSV"按钮
- 或使用快捷键 `Ctrl+E`

### 导出选项

#### 文件设置
```
文件名: [mstr_premium_data_20240101_143025]
保存位置: [/home/user/Documents] [浏览]
```

#### 数据选项
```
包含字段:
☑ 时间戳    ☑ MSTR价格
☑ BTC价格   ☑ 溢价率

排序方式: [时间升序▼]
```

#### 时间范围
```
○ 全部数据
○ 最近1小时
○ 最近24小时
● 自定义范围
  从: [2024-01-01 00:00:00]
  到: [2024-01-01 23:59:59]
```

#### 格式选项
```
文件格式: [CSV▼]
CSV选项:
  分隔符: [,▼]  ☑ 包含标题行
数值格式: [2▼] 位小数
```

### 支持的导出格式
- **CSV**: 通用表格格式，Excel兼容
- **JSON**: 结构化数据格式，编程友好
- **Excel**: 直接生成.xlsx文件 (需要pandas)

## 💡 最佳实践

### 监控策略

#### 短期交易 (5-15分钟)
- 更新间隔: 5-10秒
- 显示时间: 30分钟-1小时
- 启用声音提醒
- 设置较小的价格变化阈值

#### 中期观察 (1-4小时)
- 更新间隔: 15-30秒
- 显示时间: 2-4小时
- 关注趋势变化
- 定期导出数据分析

#### 长期跟踪 (日级别)
- 更新间隔: 60秒
- 显示时间: 8小时-1天
- 设置较大的数据点限制
- 定期清理过期数据

### 性能优化

#### 内存管理
- 限制最大数据点数量 (建议1000-5000)
- 定期清理历史数据
- 监控内存使用情况

#### 网络优化
- 合理设置更新间隔
- 避免过于频繁的API请求
- 监控API配额使用

#### 系统资源
- 关闭不必要的Chrome标签页
- 监控CPU和内存使用
- 定期重启长时间运行的监控

### 数据管理

#### 备份策略
- 定期导出重要数据
- 保存配置文件备份
- 记录重要的市场事件时间点

#### 分析技巧
- 结合多个时间范围观察
- 关注异常溢价率波动
- 记录外部事件对溢价的影响

### 故障预防

#### 连接稳定性
- 保持Chrome浏览器稳定运行
- 确保网络连接稳定
- 定期检查API密钥状态

#### 数据完整性
- 监控错误计数
- 注意数据中断时间
- 及时处理连接异常

## 🔍 故障诊断

### 常见问题自查

#### 1. 数据不更新
- [ ] Chrome调试模式是否正常运行?
- [ ] SeekingAlpha是否已登录?
- [ ] API密钥是否有效?
- [ ] 网络连接是否正常?

#### 2. 图表显示异常
- [ ] 是否有足够的数据点?
- [ ] 时间范围设置是否合理?
- [ ] 图表设置是否正确?

#### 3. 性能问题
- [ ] 数据点数量是否过多?
- [ ] 更新间隔是否过短?
- [ ] 系统资源是否充足?

### 日志分析
查看日志文件获取详细错误信息:
```bash
# Linux/Mac
tail -f ~/.local/share/MSTRMonitor/logs/mstr_gui.log

# 查看最近的错误
grep ERROR ~/.local/share/MSTRMonitor/logs/mstr_gui.log
```
