# 更新日志

## [1.0.0] - 2024-01-08

### 🎉 首次发布
- 完整的MSTR/BTC溢价监控GUI应用
- 基于Chrome远程调试协议的数据获取
- 实时价格监控和溢价率计算

### ✨ 新功能

#### 核心功能
- **实时监控**: MSTR股价、BTC价格和溢价率实时更新
- **可视化图表**: 基于matplotlib的动态图表显示
- **数据管理**: 内存中的高效数据存储和管理
- **配置系统**: 完整的设置界面和配置文件支持

#### 用户界面
- **数据卡片**: 实时显示价格和变化百分比
- **控制面板**: 直观的监控控制和参数设置
- **状态栏**: 详细的系统状态和统计信息显示
- **设置对话框**: 全面的应用程序配置选项

#### 数据导出
- **多格式支持**: CSV、JSON、Excel格式导出
- **时间过滤**: 灵活的时间范围选择
- **字段选择**: 自定义导出数据字段
- **预览功能**: 导出前数据预览

#### 高级特性
- **键盘快捷键**: 完整的快捷键支持
- **错误处理**: 完善的错误处理和恢复机制
- **日志系统**: 详细的日志记录和调试信息
- **性能监控**: 内存使用和API状态监控

### 🏗️ 技术架构

#### 模块化设计
- **核心层**: API客户端、数据管理器、配置管理器
- **服务层**: 监控服务、图表服务、网页抓取服务
- **界面层**: 主窗口、组件、对话框

#### 关键组件
- `gui/core/api_client.py`: 统一的API请求处理
- `gui/core/data_manager.py`: 线程安全的数据存储
- `gui/core/config_manager.py`: 配置文件管理
- `gui/services/monitor_service.py`: 后台监控服务
- `gui/services/chart_service.py`: 实时图表渲染
- `gui/ui/main_window.py`: 主应用程序窗口

#### 依赖项
- `requests`: HTTP请求处理
- `selenium`: 浏览器自动化
- `beautifulsoup4`: HTML解析
- `matplotlib`: 图表绘制
- `tkinter`: GUI框架 (Python标准库)

### 🎯 支持的功能

#### 数据源
- **Finnhub API**: 股票和加密货币价格数据
- **SeekingAlpha**: BTC per share数据 (通过Chrome调试)
- **实时计算**: 溢价率自动计算

#### 监控选项
- **更新间隔**: 5秒到60秒可选
- **数据限制**: 可配置的最大数据点数
- **时间范围**: 30分钟到1天的显示范围
- **自动清理**: 定时清理过期数据

#### 图表功能
- **实时更新**: 平滑的动画效果
- **交互操作**: 缩放、平移、工具提示
- **样式自定义**: 颜色、线宽、网格等
- **多时间范围**: 灵活的时间窗口选择

#### 告警系统
- **阈值设置**: 高/低溢价率告警
- **声音提醒**: 可选的音频通知
- **视觉指示**: 颜色编码的状态显示

### 🔧 系统要求

#### 运行环境
- **操作系统**: Windows 10+, macOS 10.14+, Linux (Ubuntu 18.04+)
- **Python**: 3.7+ (推荐3.8+)
- **内存**: 最少2GB RAM
- **存储**: 100MB可用空间

#### 外部依赖
- **Chrome浏览器**: 支持远程调试
- **网络连接**: 稳定的互联网连接
- **API密钥**: 有效的Finnhub API密钥

### 🚀 性能特点

#### 效率优化
- **内存管理**: 智能的数据点限制和清理
- **网络优化**: 合理的API请求频率控制
- **UI响应**: 异步数据更新，不阻塞界面

#### 稳定性
- **错误恢复**: 自动重试和故障转移
- **资源清理**: 正确的资源管理和释放
- **线程安全**: 多线程环境下的数据安全

### 🔐 安全考虑

#### 数据安全
- **本地存储**: 所有数据仅存储在本地内存
- **API密钥**: 安全的配置文件存储
- **无数据传输**: 不向第三方发送用户数据

#### 网络安全
- **HTTPS**: 所有API请求使用加密连接
- **Chrome沙盒**: 利用Chrome的安全机制
- **最小权限**: 仅请求必要的数据访问权限
